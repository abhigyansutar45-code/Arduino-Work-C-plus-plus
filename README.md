## 💻 Sample Arduino C++ Code

### 🔌 LED Blink Program

```cpp
// Arduino LED Blink Program

int ledPin = 13;

void setup() {
    pinMode(ledPin, OUTPUT);
}

void loop() {
    digitalWrite(ledPin, HIGH);
    delay(1000);

    digitalWrite(ledPin, LOW);
    delay(1000);
}
```

### ⚡ What This Program Does

- Configures Arduino digital pin 13 as an output.
- Turns the LED ON.
- Waits for one second.
- Turns the LED OFF.
- Repeats continuously.
